# FREEzzz shared gamepad skin base

The approved skin library is embedded directly into the application bundle. There is no user sticker upload.

Interaction:
1. Press **STICKER**.
2. Swipe left/right directly across the gamepad, or use **‹ / ›**.
3. The skin changes immediately in preview.
4. Press **✓** to confirm and save it for that console family.

Current shared skins:
- SUNNY TOONS
- MONSTER CARNIVAL
- BLUE GRAFFITI
- NEON CHARACTER
- STICKER BOMB
- RETRO EMBOSS
- POP ARCADE
- ANIMATED EXCLUSIVE (GIF)

The skin layer never changes button geometry, hit areas, mappings, DS touch handling, or emulator controls.
