# FREEzzz Portal local video library

Upload the seven MP4 files below into this directory. The application uses these local files as the production background-video source.

- hud-background.mp4 — HUD/sidebar background
- home-hero.mp4 — HOME hero
- home-live.mp4 — HOME LIVE block
- home-chat.mp4 — HOME CHAT block
- home-game.mp4 — HOME GAME launcher background only
- home-radio.mp4 — HOME RADIO block
- home-library.mp4 — HOME LIBRARY block

The original external URLs are kept only as source metadata in `src/video-assets.ts`; runtime background playback resolves to the local files.
