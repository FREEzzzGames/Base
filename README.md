# FREEzzz Platform

Version 0.0.1 — controlled baseline.

Repository: FREEzzzGames/Base
Branch: main

Includes HOME, LIVE, CHAT, GAME, RADIO, LIBRARY, RU/DE/EN, responsive UI, developer diagnostics, Telegram WebApp SDK boundary, local fallbacks and no portal economy.

Run:
npm install
npm run typecheck
npm run build
npm run dev

See LAW-2.0.md for the 31-stage development law. The original portal-economy Stage 21 remains permanently excluded.

## Deployment
Production GitHub Pages deployment is handled exclusively by `.github/workflows/ci.yml`.
